- 事件源文件：`events/events_src.js`（90 个事件）。运行 `node events/events_src.js` 把它嵌进 index.html，作为 `<script type="application/json" id="events">`。
- 引擎在 index.html 的 sim 里：
  - 史实日志 `u.facts`，事件 `on` 支持 year / pending / fact:* / arrival / recognize / report / choice；

  - 知识按光延迟传播；
  - 后裔只继承分家前的历史。
- Node 加载器：`tools/simload.js`。检查器：`tools/evcheck.js`（加 `--static` 只做静态检查）。在 Node 里跑 URL 计划：`tools/plan.js`（选项 `--all`、`--eval`）。
- 统计脚本：`playtest/echo_stats.js`、`playtest/r6_faith_stats.js`，以及 curse/tier/missionary 三个（已改用 simload）。

## 本轮自测中发现并修好的问题
- URL 计划或脚本可以强行选当前没有的选项，结果出现了和自己的母星结盟这种错位史实。现在 interact 会拒绝。
- 被扣押原来记成你「结怨」，会招来复仇舰队。现在改成独立的 detained 史实，并新增一条回响。
- 后裔会继承分家之后的祖先史实，导致流亡舰队把自己的清理当成「逃亡的原因」。现在 lineage 有截止年份。
- 一次到访里会同时出现多场「认出你」（旧盟和故人；朝圣和假先知）。现在加了 scene 互斥，并给信仰场景分组。
- 「坐标正在变亮」的预警等光传到时，对方已经灭亡，卡片仍然弹出。现在这种过期预警不再显示。
- 日志句首和时间线的年份重复（「纪元 378 年：纪元 378 年，」）。已去掉。
- 回响框重复了上面已经出现过的句子。现在会过滤；史料里属于你的回响改成金色标出。
- 平面星系和死寂星系的「风平浪静」文案改掉了；「流亡舰队的流亡舰队」这类病句改掉了；废墟的名字不再出现 undefined。
