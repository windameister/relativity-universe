# 相对论宇宙 · 第二轮试玩报告（玩家视角）

**怎么玩的**：用 headless Chrome（puppeteer-core，swiftshader）在真实页面上点按钮。
- 2D 用画布坐标点星；3D 用 `window.__dbg.sysO` 的屏幕坐标做真实鼠标点击，必要时滚轮拉远镜头。
- 选驱动、点启航、点弹窗选项、冬眠，读的都是渲染出来的文字。
- 3D 回放期间每 1 秒抓一次 HUD，并在关键帧截图。
- 驱动脚本：/workspace/playtest-tool/a.js。

**4 局，全是新种子，共约 55 个决策**
- **A（2D）外交家 `seed=dip7`**：贸易、交换技术、结盟，回家讲述，考古。
- **B（3D）传教士神 `seed=prophet`**：降临（被当恶魔），回来假扮神明，再回访，然后去做学者文明的样本。
- **C（2D）拾荒者 / 考古者 `seed=relic9`**：追飞船科技，拾荒、考古、求教，冬眠 1000 年。
- **D（3D）末日广播者 `seed=zero`**：广播 7 处坐标（含母星），远处冬眠看二向箔落下，直到收到归零者广播。

**补充**：另外用 3 个 node 统计脚本补证据，都在本目录。
- `home_stats.js`：母星被打击的概率。
- `missionary_stats.js`：宗教回响能走多远。
- 也复跑了上级目录的 curse / tier 统计。

## 总体结论（对比第一轮）
- **明显进步**：
  - 第一轮“到访即死刑、后期全是拦截墙”这两大问题基本解决：到访被打击 37%，对照组 14%；先进文明里只有 30% 是拦截墙。
  - 最重要的是有了**因果句**。“因果：你的曲率航迹在纪元 544 年被歌者看到（那是纪元 380 年前后从这里发出的光）；纪元 706 年，一片二向箔落在这里”这种话，第一次让我真的觉得是我干的。
  - 3D 回放好看到让我愿意盯着等。
- **新的天花板**：
  - **事件是线性阶梯，不是故事**：同一模板反复出现，“泊位 / 星图做生意”在一局里出现 8 次以上。
  - **线索断在半路**：盟友变成屠夫、地球成了黑暗森林猎手、流亡舰队不认得我，这些都没有被讲出来。
  - **资源层没有压力**：补给和母星回家太宽松。
- **总体**：从“机制原型”升级成了“有叙事骨架的原型”，但还没到“每局都是不同故事”。

## 最好的 3–5 个时刻
1. **（A）回家，太阳系被压平了**
   - 大事件卡写着“你再也没有家可以回了”，下面一行因果把锅落到我在 376 年那次曲率出发上。我在家门口停了一下、讲完故事就走，结果害死了母星。负罪感是真的。
   - 截图：A-home-flat-causal.png
2. **（B）驱魔节**
   - 我降临，被石器部落当成恶魔。300 年后回去，“孩子们每年都过「驱魔节」，戴着照你的飞船做的面具”。
   - 这是全程最有画面感的一句回响。接着我改扮神明，想看恶魔变成神的戏码。
3. **（D，3D）三片二向箔在回放里次第落下**
   - 时间流速从 ×87 年/秒骤降到 ×0.3，前沿带着光晕膨胀，几个二维区域彼此咬合，标签写着“以光速扩张中”。截图：D3d-replay-14.png
   - 单片二向箔的大理石纹球体也很震撼。截图：B3d-replay-foil1.png
4. **（C）醒来发现地球干的**
   - 我在“铎焰第二共和国”轨道上冬眠 1000 年，醒来恒星死了。因果写着“「地球文明」的深空监听网在纪元 434 年发现了他们”：是我的母星干的。后来纳弥人也是这样。
   - 还有一次冬眠第 767 年主控故障，被紧急唤醒，这种小事故很有味道。截图：C-home-killed-neighbor.png
5. **（B，3D）学者团登船**
   - 冬眠醒来时，“学者团就登上了飞船……记录你的语言、导航算法，甚至舰员的梦”。先进文明的性格化确实有效，比第一轮那堵墙好太多。

## 仍然无聊、重复、困惑或不公平
- **回响模板单一、重复**
  - teach / trade / ally 共用两句：“港口为远方旅人保留着一个泊位，铭牌上刻着「X号」” 和 “商人至今还在用你带来的星图做生意”。
  - 每做一次交易就再刷一遍。dip7 里同一个文明的泊位出现了两次（286、398 年）。
  - 只交换过技术，也说我“带来星图”。
  - 回响在“这些年发生的事”和“你留下的回响”里重复列两遍。
- **结盟没有后果**
  - 我和蒙赫、祁崆都结了盟，母星被承认为友邦。结果祁崆在 667 年和地球开战，713 年“征服”了已经被压平的地球，盟约一句没提。
  - 盟友 497 年用光粒清理了一个石器部落，因果写的是“祁崆议会的深空监听网”，也不说“你的盟友”。
- **故事主体弄错**
  - 大事件卡“「蒙赫联合政府」灭绝了：纪元 112 年你曾与他们通商的那个文明”。用的是旧名，也挑错了关系：我跟他们是结盟，而且结盟时他们已改名「蒙赫议会」。
- **传教线太脆**
  - B 局里我刚改扮神明，34 年后这个部落就被歌者光粒抹掉了，宗教一步都没长出来。
  - 统计 258 个样本：1500 年内 73% 的“神眷文明”灭亡。即便活着，走到“使者号出发找神”的也只有 36%。
  - “找到飞船”在统计里是 0（飞船停在远处时），传说中的会面几乎碰不到。
- **补给和母星回家的套利**
  - 地球扩张后，每个地球殖民地都是“母星回家”：补满补给，还送科技（+3.6、+8.4、+14.6）。后期抵达里 21–29% 是“母星”。
  - 拾荒者的正确玩法变成了“回家睡觉”：在太阳冬眠 3×1000 年，飞船科技从 60 涨到 110.8。拾荒 +4.2、考古 +0（遗迹科技低于飞船），完全比不过。
  - 我整局补给最低 75，从来没紧张过。
- **冬眠在恒星旁边，恒星被光粒熄灭，我毫发无伤**：C 局，已知问题，但很出戏。
- **母星坐标反复被抽**：被扣押时“抽走太阳的坐标”，可太阳已经是一幅画（D 局，同第一轮）。
- **记忆和态度互相矛盾**：“1647 年过去，你只剩下一个模糊的神话：「入侵者」”，态度显示“中立”，同一屏又“记得你是入侵者”，直接扣押 14 年。
- **流亡者不认人**：我帮过的乌塔议会被压平后，流亡舰队把我当“飞进机场的麻雀”无视（C 局）。
- **新物种太少**：B 局到中期已经没有可以传教的落后文明。“传教士”这种玩法几百年后就没东西可玩。
- **归零者广播太轻**：只是一行“旅程里程碑”。3D 回放里 862 年那一刻直接以 ×196 年/秒“暂时风平浪静”飞过去，一个画面都没给。

## 回响和因果系统让我觉得要负责吗
- **会，但只在一种情况下**：因果句明确写“你的曲率航迹 / 你的广播”。A 局母星、B 局井宿一都是。
- **反过来就失效**：
  - 太多死亡写的是“某某的深空监听网发现了他们”。我知道背后可能是我的交易、技术交换或盟约抬高了对方，但游戏不说，我就不觉得是我。
  - 正面回响太模板化（泊位、星图），记不住，也没让我觉得“这是我种下的”。
- **最强的负罪感**：来自“具体人物 + 具体仪式”，比如驱魔节的面具。
- **最弱的**：数值后果，比如“科技 +1.5”。

## 补给、寿命、事故有没有意义
- **补给**：几乎没意义。补给源太多（母星殖民地、贸易、考古、拾荒、结盟都补满），我从没低于 75。
- **寿命 105 岁**：
  - 有意义，是长眠玩法唯一的硬边界。plan `h:1000` 四次后死在第 3650 年，死亡文案很好。
  - 但冬眠按钮没有预告“醒来时 X 岁 / 会不会死”。航行有预告，冬眠没有，第四次 1000 年属于踩坑。
- **冬眠事故**：触发过一次（第 767 年主控故障，多老几岁、耗补给），有味道，但没造成决策压力。

## 3D 观感
- **好看**
  - 二向箔区域是大理石 / 梵高漩涡纹的半透明体，边缘有光晕，标注“以光速扩张中”。多片相互咬合时很震撼（D3d-replay-14）。
  - 碎片飞行带彩色虚线轨迹（D3d-replay-1000a）。
  - 光粒冲击是半透明光壳加十字星芒（B3d-replay-1000）。
  - 银河带和星云背景有质感。
- **回放节奏**
  - 事件处减速到 ×0.2–3 年/秒、空档 ×90–200 年/秒，这个想法对。
  - 但无事件的旅程也要放 4–5 秒“暂时风平浪静”。300 年冬眠约 17–25 秒，1000 年约 22 秒，最后在终点年份停 5–9 秒才弹报告。连续操作时偏拖，我会想按跳过。
- **可读性**
  - 星名标签很小，太阳附近互相重叠。
  - 默认镜头拉近后远处的星全部隐藏，我得滚轮拉远才能点到目的地。
  - HUD 同时堆三行事件文字，读不过来。
- **假或不一致**
  - 二维化被画成一个三维球体，表现的是“球形区域跌落”，但看起来像个彩色泡泡。
  - 回放明说“不计光延迟”，所以会提前播出报告里因为光延迟还看不到的事（比如太微九的二向箔），和游戏核心规则打架。
  - 第一次 300 年回放时，顶栏“宇宙维度”在 408、421 年还显示 3.000（0 次），而前面已经落了 2–3 片二向箔（D3d-replay-10/14）。后一段回放又正常更新。
  - swiftshader 下约 10–11 fps，真机可能不同。

## 规则化、历史条件化的事件库最该用在哪里
下面这些地方，我都觉得“这一刻值得一个专属事件，但游戏给了模板句或者什么都没给”。

1. **盟友 / 贸易伙伴变成屠夫或敌人**
   - 条件：你与 X 结盟或交换技术，之后 X 发动黑暗森林打击，或与你的母星开战。
   - 产出：X 的使者来解释或要求你选边；母星质问你；后续给出“调停 / 背弃 / 报复”的选项。
   - 同时关掉“节日纪念盟约”这类温情回响。
2. **母星成为猎手**
   - 条件：地球清理过别的文明。
   - 产出：回家时出现“地球的清理档案里有你当年的星图”、你能读到地球的决策记录，或者受害者的流亡舰队来找你复仇。
3. **流亡者和后代认人**
   - 条件：你帮过或伤过的文明被灭，留下流亡舰队。
   - 产出：流亡舰队有专属的“认出了「回声号」”事件（报恩、怪罪、索要母星坐标）。不要落到通用的“冷漠”池。
4. **宗教的分叉树，取代线性四步阶梯**
   - 分叉条件：恶魔转神、神转恶魔（我先恶魔后神的情况完全没被处理）、你回访的次数、文明的科技 / 稳定度、有没有战争。
   - 可能的分支：改革派、殉道者、圣地朝圣、伪先知冒充你、信徒点燃射电呼唤导致自身暴露、使者号与你真正会面。
   - 前一阶段的结果解锁或关闭后续；“驱魔节”这种已经发生的仪式也应该在后续文本中被引用。
5. **共同的敌人**
   - 条件：你得罪过的 A 和 B 开始交往（D 局：地球和翡霍在我广播后 366 年建交）。
   - 产出：“两个被你出卖的文明结成反『回声号』同盟”、联合追捕。
6. **大事件后的余波链**
   - 母星压平后：地球流亡舰队寻找你、你成为“最后的地球人”的身份事件。
   - 归零者广播后：文明分裂为“回归派 / 降维派”，黑域文明的态度变化，你自己能不能响应回归运动。
   - 现在这些都只是一行字，故事到此为止。
7. **复用遗迹叙事**：考古只给“壁画、乐器、补给 +10”。应该根据废墟主人的历史（死于谁、是否被你帮过、是否信奉你）生成不同的发现。比如在信奉你的遗迹里看到你的神像。

**实现建议**：每个事件带 `trigger`（谓词：历史标签 / 关系 / 数值）、`weight`、`once` 或 `cooldown`、`unlocks`、`blocks`、`text` 模板（可引用历史中的专名和年份）。所有已发生事件写进一条 history tag 表，后续谓词去查它。这样“驱魔节”可以在 600 年后被“使者号船员戴着同样的面具”引用。

## 改进 Top 5（按对乐趣的影响排序）
1. **上事件库，先做上面 1–4 四条线**（盟友 / 母星猎手 / 流亡者认人 / 宗教分叉树）。回响按关系去重：同一文明同一类回响只出一次，不再刷“泊位、星图”。
2. **把“你的间接责任”写进因果句**：比如“你在 163 年交给他们的曲率理论，让他们在 415 年进入星海时代；497 年他们清理了霍琉部族”。不只是航迹和广播。
3. **收紧补给和成长经济**：
   - 只有母星本体回家才补满、送科技；殖民地只给少量补给，送科技上限每 N 年一次。
   - 考古、拾荒的收益与遗迹峰值科技挂钩，可以超过飞船当前科技。
   - 让“回家睡觉”不再是最优解。
4. **重大时刻要有仪式感**：
   - 归零者广播、母星压平、盟友灭亡，在 3D 回放里减速并单独演出。
   - 冬眠按钮显示“醒来时 X 岁、会不会死、事故概率”。
   - 回放尊重光延迟，或者明确标“上帝视角回放”并可选关闭。
5. **保护玩法线索不被随机打断**：对玩家深度投入的文明（神、盟友），给歌者或黑暗森林打击加“剧情保护期”或预警事件（“他们的射电望远镜对准了天空，你要不要警告他们？”）。让玩家有机会干预，而不是回来就看到死讯。另外新智慧物种的诞生率提高一点，或者和二维化、黑域后的空白区挂钩，保证中后期还有可以传教的落后文明。
