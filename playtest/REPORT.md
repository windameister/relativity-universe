# 相对论宇宙 · 试玩报告（玩家视角）
试玩方式：用无头 Chrome（puppeteer-core）点真实按钮：点星、选驱动、启航、点弹窗选项、冬眠。读的是页面渲染出来的文字。驱动脚本在 /workspace/playtest-tool/a.js。
打了 4 局，共约 50 个决策：
- cautious1：谨慎探索
- god2：假扮神明、送技术
- boom3：乱广播
- sleep4：长眠者
另外两个统计脚本：curse_stats.js、tier_stats.js（各 150~200 个种子）。

## 爽点
1. cautious1：第一趟用常规推进飞 929 年，回家发现地球在 225 年被埃汐共同体征服。再回去时（1385 年），太阳已经被二向箔压成画。凝视后读到歌者签名，像“一首随手哼出的歌”。
2. cautious1：在紫微八留下少量技术，243 年后回来，那里已经死寂。弹出一句“也许正是那份礼物让他们过早地暴露在深空之中”，真有负罪感。
3. boom3：广播坐标时给出“光要走 169 年才到清理者那里，武器还要再飞差不多这么久”，延迟后果的预期感很好。回地球时被记成「入侵者」，被舰队驱逐。
4. 流亡链：二向箔砸下，流亡舰队逃到别的星系。几百年后我在那里撞见「塔泽流亡舰队」或「埃汐流亡舰队」，有历史在流动的感觉。
5. sleep4：冬眠 1000 年醒来，地球已经成了会清理别人的黑暗森林猎手（874 年清理了库汐部族），这个反转好。

## 无聊、困惑、不公平
- **到访即死刑**（最大问题）：曲率进出各加 0.6 暴露，合计 1.2，超过 SINGER_THRESH=1.0。flagExpo 记最大值，之后 dS+200 年里每年约 2% 掷骰。
  - 统计：曲率到访的外星文明 600 年内被打击 77%，留少量技术后 98%，没去过的对照组 19%。
  - god2：到访的 4 个外星文明全灭；“假扮神明”的宗教后果一次都没看到。
  - 文案却把锅甩给“礼物”，真正的凶手（航迹）不提，玩家学不到规则。
- **后期全是先进拦截**：后 8 站中“先进”占 55%（前 7 站 15%）。文案同一段：“你一减速就被…拦截审查…你没有任何能给他们的东西”，加上同样 5 个按钮。
  - “交出星图”在星图刚被抽走后仍然可选。
  - 有通行证时照样先显示审查文字。
- **飞船科技涨得太慢**：文明能涨到 160，我卡在 60~76，差距只会越来越大。地球最后 160，比歌者 150 还高。
- **崩溃和改名刷屏**：“社会崩溃，大量知识失传 / 改称××遗民 / 重建同盟 / 第二共和国”几乎每个文明都来一遍。“贸易破裂→17 年后和约”每隔几百年重复一次。
- **名字太像**：埃汐 / 埃岚、岚奥 / 荻伊，一个宇宙里分不清谁是谁。
- **选择不重要**：观察不干预、贸易、结盟后来几乎看不到回响。用同一随机流测，观察和不互动的结果完全一样。舰员年龄 179 岁也没有后果。
- **常规推进加冬眠是免费时光机**：1000 年只老 20 岁，没有资源或寿命约束，长眠没有代价。
- **UI**：
  - 星名标签重叠（心宿十一和参商八、螣蛇二一带）。
  - 窄窗口（800 宽）时顶栏盖住地图。
  - 远方消息挤成一段长文，地球被压平这种大事埋在“你去过的其他地方”里。
  - 每次行动后都跟一句“他们会记住你”，对废墟和二维画也说。

## “几百年后回来，一切都变了”成立吗
成立，而且很频繁：统计里 67% 的回访有明显变化（换主、死亡、变二维、科技差 10 以上）。我 4 局里每局至少 1 次被震到，cautious1 有 3 次。
问题是变化太单调，几乎都是“死了 / 被压平 / 封进黑域 / 崩溃改名”，很少有“我种下的种子长成了什么”这种正面或复杂的回报。还有：
- 回到母星没有特殊待遇。
- 冬眠在家门口照样“一减速就被拦截”。
所以冲击力在第 2、3 次之后迅速衰减。

## 改进 Top 5（按对乐趣的影响排序）
1. **修暴露模型，让因果可读**：
   - 航迹暴露按距离和时间衰减，flagExpo 不要锁最大值。
   - 回访报告明确写“你的曲率航迹 / 你交出的星图 / 你的广播 → 被谁在哪年看到 → 打击”。
   - 让玩家能用常规推进、静默、低调访问去规避。
   - 这样“我害死了他们”才是可学习的选择，而不是必然。
2. **重做先进文明接触**：
   - 按态度、扩张欲、印象给出不同剧情：好奇的学者、冷漠的官僚、把你当文物展示、雇你当信使去别处。
   - 已经抽走过星图的不要再抽；有通行证就直接放行。
   - 给飞船科技合理的成长线（遗迹、结盟、求教累积），避免后期 55% 都是同一个墙。
3. **让礼物和神话有正向、复杂的回响**：宗教分裂、以你命名的星舰、几百年后来找你报恩或复仇的后代、你教的技术被用于战争。至少一半回访要讲“你造成的”而非“随机发生的”。
4. **重大事件单独成卡，并放进地图**：母星被压平、你帮过的文明灭绝，都应单独弹卡或做成时间线回放，别埋在远方消息段落里。
   - 已二维化的星系在远方消息里显示“二维画”，不是“已死寂”。
   - 名字生成器拉开差异。
5. **给长眠、长寿加代价和目标**：舰员寿命和冬眠事故率、补给和维修要靠停靠文明，再加一个终局目标（逃离归零 / 加入黑域 / 找到歌者 / 让地球活到纪元 N）。现在到第 3000 年以后就没有理由继续玩。
