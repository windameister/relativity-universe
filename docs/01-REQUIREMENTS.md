# 需求与硬规则

本文记录发起人对这个游戏的构想，以及后来明确纠正过的物理和设定。后面做正式版时，这些规则优先于任何「看起来更炫」的改法。

相关实现见 `docs/ARCHITECTURE.md`。迭代过程见 `docs/02-ITERATION-HISTORY.md`。

## 1. 长期构想

这是一个程序化生成、用数学方法建模的、接近真实的**星系尺度宇宙沙盒**。

想象的世界接近银河系的一个局部：恒星、黑洞、星团、星云。玩家可以在恒星之间旅行，看到文明按自己的节奏演化。一趟旅行对船上的人可能只过了很短的时间，宇宙和母星却可能过了几百年。

玩家不该被锁死在单一身份里，而应能在这些角色之间切换或融合：

- 探索者：去没人去过的地方，把光年外的历史读回来
- 文明构建者：留下技术、航线、信仰或警告，看它们几百年后变成什么
- 角色扮演角色：有寿命、补给、选择带来的名声和罪责
- 飞行员：在常规推进和曲率驱动之间做真正有代价的航行决策

核心体验不是「一张大地图上的即时战略」，而是：**你离开以后，世界在你看不到的地方继续走；等你再见到它，见到的是已经走完、并且受光速限制的那一段历史。**

## 2. 物理硬规则（必须遵守）

下面几条是发起人明确纠正过的，不能写成「三体式超光速」或「随便加点能源就能接近光速」。

### 2.1 没有东西能超过光速

任何航行、武器、信号，外部时间都必须满足：

\[
t_{\mathrm{ext}} \ge \frac{d}{c}
\]

实现里用光年、年，c = 1。`test_sim.js` 把「外部时间 < 距离」视为致命错误（`FTL!`）。

### 2.2 时间膨胀必须是真实的相对论

船上固有时由洛伦兹因子给出，不能另写一套「曲率时间」：

\[
\gamma = \frac{1}{\sqrt{1-\beta^2}},\qquad t_{\mathrm{ship}} = \frac{t_{\mathrm{ext}}}{\gamma},\qquad t_{\mathrm{ext}} = \frac{d}{\beta}
\]

曲率航行时，船上时间非常短，外面可以过一个世纪。这是设计要保留的「几百年后回来，一切都变了」。

### 2.3 曲率驱动并不超光速

《三体》里的曲率驱动，在本项目中的规定是：

- **它从不超过 c。**
- 它只是把飞船推到 c，或任意接近 c（原型里可选 0.999c / 0.9999c / 0.99999c）。
- 加速过程视为几乎瞬间完成，相对整段航程可忽略。
- 外部时间 ≈ 距离 / c；船上时间 = 外部时间 / γ，极短，舰员可以清醒航行。
- 代价：在出发地和目的地留下长久可见的曲率航迹，暴露坐标，提高被黑暗森林打击的风险。

不要做成跃迁、虫洞或「几秒跨过几百光年而宇宙时间几乎不动」——那会破坏光延迟和因果。

### 2.4 常规推进永远接近不了光速

无论使用什么能源、有没有工质，常规推进都不可能接近 c。这是硬限制，不是平衡数值上的暂时设定。

原型把常规推进上限取在 0.03c（可选 0.01c / 0.03c）。此时 γ ≈ 1，船上时间 ≈ 外部时间，一趟动辄几千年。舰员必须在冬眠舱里，生理衰老降到 1/50。

含义：

- 想在有生之年做跨越式探索，只能用曲率驱动
- 用常规推进更隐蔽，但要付出寿命、冬眠风险和「外面已经换了好几个时代」的代价
- 二维平面以光速扩张时，常规推进跑不掉，只有接近光速的曲率飞行才能逃

### 2.5 光延迟是世界规则，不只是特效

某件事发生在星系 S、年份 y，观察者在 O，只有当 `now ≥ y + D[S][O]` 时才能知道。地图、远方消息、接触时提到的母星近况，都应该显示「光已经传到这里的样子」，而不是上帝视角的真实现状。

3D 回放目前按事件真实时刻播放、不计光延迟，这是已知的不一致，正式版需要处理（标明「上帝视角回放」，或改成遵守光延迟）。

## 3. 宇宙与文明

### 3.1 程序化银河局部

每局用种子生成 22–29 个恒星系统，分布在约 200 光年见方的银盘局部：两条带状悬臂加散点，近似星团结构。保证至少有一个黑洞，并点缀星云。0 号星系永远是太阳，地球文明从这里出发。另外有 2–4 个外星文明，科技从石器到星际不等。

这是「银河系尺度感觉」的原型切片，不是整条银河的恒星级模拟。正式版如果要画得更像真正的银河，仍然应该让可交互的文明世界保持可计算、可追溯，而不是把亿万恒星都做成活的智能体。

### 3.2 文明是演化出来的，不是刷出来的

每个文明用少量状态量演化：人口、科技、资源、扩张欲、稳定度。每年按承载力、压力、贸易、战争和随机事件推进。科技到了阈值会殖民、接触、开战，或对弱者发动黑暗森林打击。空的宜居星系有很小概率诞生新的石器时代文明。

文本和离散剧情（崩溃、改名、宗教、回响、大事件）应尽量写成事件数据，而不是写死在模拟代码里。

### 3.3 互动取决于科技差

接触不能套同一张选项表。玩家飞船有自己的科技等级（原型起始为 60），和当地文明的差距决定场景：

| 层级 | 大致含义 | 玩家能做的事 |
|---|---|---|
| 原始 | 对方还在石器或刚起步 | 几乎无法对等交流，可观察、降临，也可能被当成神或恶魔 |
| 落后 | 明显弱于飞船 | 可留下少量或大量技术、假扮神明 |
| 对等 | 谁也压不住谁 | 交换技术、贸易、结盟、对峙 |
| 先进 | 对方远强于你 | 主动权在对方：学者、官僚、商人、收藏家、冷漠、好战，结果完全不同 |
| 母星 | 地球文明一脉 | 应该欢迎你回家，而不是把你当入侵者拦截 |
| 遗迹 / 无人 / 二维 / 黑域 | 没有可对等谈判的对象 | 考古、凝视、离开，或面对不可进入的黑域 |

先进文明不该全部变成「一减速就被拦截审查」。礼物、星图、广播、结盟会在几百年后长出不同的后果，这些后果必须能追溯到玩家做过的事。

## 4. 《三体》宇宙法则（要的是法则，不是贴皮）

发起人明确希望这个宇宙里有：

- **黑暗森林法则**：暴露坐标是危险的。高等文明可能直接清理暴露的弱者，而不是先开外交。
- **歌者文明 / 神级文明**：远在星图之外，玩家不能接触。它巡航、观看、随手清理。科技远高于普通星海文明（原型里歌者科技 150，普通星海门槛 75）。
- **二向箔 / 二维化打击**：把三维空间压成二维。平面以光速扩张，被吞没的星系永久变成「一幅画」。
- **光粒打击**：接近光速的破坏性打击，用于不够「值得」动用二向箔的目标。
- **宇宙维度坍缩**：每一次降维打击都让宇宙的维度永久流失一点。累积之后会出现物理常数漂移、归零者的「回归运动」广播，最终进入低维化末期。
- **黑域**：把局部光速降到极低，换取绝对安全，但永远与宇宙隔绝。

这些不是彩蛋，而是世界运行的方式。玩家的曲率航迹、广播和星图应当能进入这条因果链。

## 5. 叙事：由历史驱动的事件库

发起人希望有一个**规则化、概率性、由历史驱动的事件库**，而不是写死的任务线。

原则：

- 事件是数据，和模拟代码分开
- 每个事件有触发条件和权重
- 发生后写入「史实」；后续事件由史实解锁、排期或封死
- 每局都可以不一样，但每件事事后都能追溯到已发生的历史
- 可见性受光延迟约束

事件库第一阶段已经做成。四条优先故事线也已能触发：

1. 盟友变成屠夫（调停、质问、站队、广播坐标报复）
2. 母星成为黑暗森林猎手（清理档案、流亡者找你复仇）
3. 流亡者 / 后代认出你的飞船（报恩、怪罪、索要星图）
4. 宗教分叉（伪先知、分裂、圣战、殉道、朝圣、改革派、使者号）

还要求选择是有代价的：停在被光粒打中的恒星旁会有生命危险；冬眠要让玩家事前看到醒来时多少岁、会不会老死。

## 6. 画面与演出

发起人要的不是示意图，而是「动画的、有真实感的 3D 宇宙渲染」，尤其是：

- 二维化打击：空间本身在跌落，而不只是给星系换一个图标
- 光粒打击：逼近、命中、冲击波，要能感到威胁
- 曲率航迹、黑域、熄灭的恒星、银河和星云，要能一眼读懂
- 离开期间的时间压缩回放，应让人愿意看，而不是干等

当前 3D 原型已经能演出二向箔扩张、光粒冲击、曲率尾迹和部分回放，但观感上二维化仍偏「彩色球体」，回放节奏偏慢，部分演出还不完整。正式版要把渲染和模拟内核分开，渲染可以换引擎，但不能改写第 2 节的物理。

## 7. 正式版要达到的感觉

发起人在原型越来越好玩之后提出的下一目标：

> 真正做成一个可以玩的、更好玩的，并且画面渲染更逼真、更震撼的版本。

「更好玩」在已有试玩里已经被反复定义过，不只是加内容：

- 因果可读：玩家能学会「我做了什么，几百年后为什么会这样」
- 选择有分歧：同一类行动不要总走到同一段剧情
- 资源与寿命有压力：补给、冬眠、回家不能变成没有代价的时光机
- 重大时刻有仪式感：母星被压平、归零者广播、二向箔落下，不应只是日志里的一行字
- 每局是不同的故事，而不是同一套模板换名字

「更逼真、更震撼」指渲染和演出，不能以破坏相对论、光延迟或黑暗森林因果为代价。
